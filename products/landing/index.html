# tidewatch

Check tide times for any coastal station from
your terminal, with alerts before high water.

## Install
    pip install tidewatch   # Python 3.10+

## Quickstart
    tidewatch search "Monterey"
    tidewatch today --station 9413450

## Options
| Flag        | Default | Description             |
|-------------|---------|-------------------------|
| --station   | none    | Station ID to query     |
| --units     | ft      | ft or m                 |
| --alert     | off     | Notify N min before high|

## Data source
Tide predictions come from a public tide API.
Results are predictions, not measurements.
