## Title

Claude Code Skills Starter Pack: 5 Skills for Freelance Developers

(Short version, 50 characters or fewer: "Claude Code Skills Pack for Freelancers")

## Description (150 words)

Stop writing the paperwork around your code by hand. This pack adds five tested skills to Claude Code that take care of the jobs freelance developers keep putting off:

- **PR Description Writer**: reviewer-ready pull requests based on your real diff, following your PR template.
- **Changelog from Git**: release notes, GitHub releases, or plain-English client update emails from any tag or date range.
- **README Generator**: scans your stack, commands, and env vars, then writes a README that only claims what it can check. Includes a client-handoff mode.
- **Scope & Invoice Drafter**: turns a messy client email into a scope of work with exclusions and milestones, an invoice, or a change request.
- **Dependency Audit Summary**: runs npm, pip-audit, cargo, and Go audits, then gives you a ranked fix list with upgrade commands and a client-friendly summary.

Helper scripts only read your repo and need nothing beyond the Python standard library. Install with one copy command. Includes a commercial license for client work.

## Price recommendation

**Launch price: pay what you want, $0 minimum, suggested $9. After the first 10 to 20 buyers or reviews, switch to a fixed $12.**

Why:

1. **Similar paid products sell for $9 to $29.** A search on 2026-09-24 found a "Claude Code Power User Kit" at $9+, single Claude Code marketing skills at $9, $12, $15, and $19 each, a "Claude Code Investment Skills" pack at $29, and a "Claude Code Migration Playbook" at $19 (URLs below). A 5-skill general developer pack sits at the low-to-mid end of that range.
2. **Free alternatives are everywhere**: anthropics/skills, a 380-skill GitHub repo, AugmentClaude's "800+ free skills", and awesome-claude-skills. A high fixed price for a small pack from a new seller with no reviews would struggle. Pay-what-you-want with a $0 minimum brings in email signups and early feedback, and a suggested $9 anchors the value.
3. **What sets it apart is freelancer workflows** (scopes, invoices, client updates, client-facing audit summaries), which the free developer-tool lists mostly do not cover. That is what supports moving to $12 once the pack has social proof.
4. **Optional upsell later:** a "Team license" at $39 that allows use across several organizations.

Caveat: I could not see the actual prices of some competitors. Gumroad product pages were blocked by the sandbox network proxy, so the prices above come from search-result snippets, not from checking the pages. Before setting the final price, open 3 to 4 competitor pages by hand.
